# SkillStream AI

An AI-powered learning companion designed to turn a TV into an interactive classroom.

## Inspiration

Learning is often associated with phones and laptops, but a large screen can provide a more comfortable and accessible learning experience.

SkillStream AI explores how Fire TV can become an interactive learning platform where users can learn topics, receive AI-powered explanations, take quizzes, and track their progress.

## Features

- TV-friendly learning interface
- Topic selection
- AI-style lesson experience
- Interactive quizzes
- Learning progress tracking
- Designed for large-screen navigation
- Expandable architecture for AWS AI integration

## Technology

- HTML5
- CSS3
- JavaScript
- Amazon Fire TV concept
- AWS
- Generative AI
- Amazon Bedrock integration planned for the production version
